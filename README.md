# Digimon Data Analysis – Attack Performance Benchmarking

## Overview
This project explores a Digimon dataset using Python, Pandas, and Matplotlib.  
The goal is to analyze attack values, identify patterns in the data, and compare performance across different Digimon types and stages.

## Objectives
- Understand the structure of the dataset
- Clean and validate the data
- Analyze the distribution of attack values
- Compare average attack values across Digimon types
- Compare average attack values across Digimon stages
- Identify top-performing Digimon

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Steps
1. Load and inspect the dataset
2. Check data types and missing values
3. Generate descriptive statistics
4. Visualize the distribution of `Lv50 Atk`
5. Compare average attack by `Type`
6. Compare average attack by `Stage`
7. Identify the strongest Digimon in the dataset

## Key Insights
- Most Digimon have mid-range attack values, while a small number are clear outliers.
- Average attack differs across Digimon types.
- More advanced stages tend to show higher attack values.
- Some Digimon stand out significantly as top performers.
